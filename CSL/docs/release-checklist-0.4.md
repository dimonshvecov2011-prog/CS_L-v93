# Чек-лист CS:L 0.4

## До pre-release

- [ ] Windows: лаунчер открывает WPF-окно без ошибок.
- [ ] Windows: игра запускается через официальный `cstrike/gameinfo.txt`.
- [ ] При исследовании HUD командная строка содержит `-insecure`; VAC-серверы не используются.
- [ ] Установка, обновление и удаление изменяют только `cstrike/custom/csl_hud`.
- [ ] Соседний файл в `custom` сохраняется.
- [ ] `ClientVersion` проверяется по списку совместимых сборок.
- [ ] Повреждённый HUD определяется по SHA-256 и пересоздаётся.
- [ ] Ошибка установки восстанавливает предыдущую папку HUD.
- [ ] В игре выполнены `path` и `version` в консоли.
- [ ] Главное меню открывается без ошибок монтирования.
- [ ] Загружена тестовая карта; проверены текстуры, модели и звуки.
- [ ] Проверен локальный HUD на 4:3 и 16:9.
- [ ] Проверено поведение при `sv_pure`: пользовательские файлы могут игнорироваться.

## Ограничения публикации

До выполнения Windows-проверки выпускается только pre-release или внутренний build. Стабильные теги `v0.3.6` и `v0.4.0` не создавать автоматически. Реальный DLL-runtime не включать без отдельного подтверждения способа загрузки и независимого `-insecure` gate.
