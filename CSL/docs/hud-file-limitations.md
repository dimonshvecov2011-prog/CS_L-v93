# Ограничения файлового HUD CS:L v1

Файловый HUD в `cstrike/custom/csl_hud` — это безопасный исследовательский слой без DLL и без клиентской логики. Он может менять только те панели, цвета, шрифты, layout-ключи и прицелы, которые конкретный клиент CS:S действительно читает из `resource/*.res` и `scripts/hudlayout.res`.

Файлами нельзя добавить новую C++-логику, получать данные, которых игра не отдаёт существующему интерфейсу, реализовать серверный протокол, выполнить сетевые решения, читать память процесса или изменить aim/recoil/fire. Файлы также не дают гарантии приоритета над штатным HUD: неподдерживаемые ключи могут быть проигнорированы.

Сервер с `sv_pure` может игнорировать или ограничивать пользовательские материалы и ресурсы из `custom`. Поэтому наличие файлов в каталоге не означает, что они будут видимы на каждом сервере. Проверять нужно локально и только с `-insecure`; к VAC-серверам с режимом исследования HUD не подключаться.

Лаунчер управляет только `cstrike/custom/csl_hud`: перед установкой проверяет `ClientVersion`, сверяет SHA-256, ставит пакет через staging и откатывает предыдущую папку при ошибке. Соседние каталоги `custom`, VPK, DLL и `gameinfo.txt` не трогает.
