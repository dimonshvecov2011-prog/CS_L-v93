# Ручная проверка запуска CS:S через `-game`

Цель проверки — убедиться, что текущая Steam-версия CS:S запускается с отдельным профилем вне папки игры и подхватывает содержимое `custom/`. Проверка не изменяет файлы Steam.

## Что понадобится

Нужны Windows с установленной через Steam Counter-Strike: Source и запущенный Steam. Лаунчер читает официальный `cstrike\gameinfo.txt`; шаблон не должен подменять SearchPaths реальной установки.

## 1. Найдите папку игры

В Steam откройте свойства Counter-Strike: Source → «Управление» → «Просмотр локальных файлов». Запишите полный путь к папке, далее обозначаемый как `GAME_ROOT`.

Проверьте наличие `cstrike\gameinfo.txt` и запишите, какие исполняемые файлы есть в корне: `cstrike.exe`, `hl2.exe` или оба.

## 2. Сверьте официальный SearchPaths

Откройте `<GAME_ROOT>\cstrike\gameinfo.txt` и сохраните блок `SearchPaths`. Проверьте список архивов в папках `cstrike`, `hl2` и `platform`, включая пары вида `*_dir.vpk` и `*_000.vpk`. CS:L переносит эти пути в профиль, заменяя `|gameinfo_path|` на `<GAME_ROOT>\cstrike`, а `|all_source_engine_paths|` на `<GAME_ROOT>`, затем добавляет `custom/*` профиля первым и отдельный путь записи профиля.

## 3. Создайте тестовый профиль

Создайте профиль вне папки игры, например:

```text
C:\CssTest\profile\
├─ gameinfo.txt
└─ custom\
   └─ test\
```

Создайте `gameinfo.txt`, заменив `{GAME_ROOT}` на путь к игре с прямыми слэшами:

```text
"GameInfo"
{
    game        "CS:S Test Profile"
    title       ""
    type        multiplayer_only

    FileSystem
    {
        SteamAppId 240
        SearchPaths
        {
            game+mod+custom_mod   |gameinfo_path|custom/*
            game+mod              |gameinfo_path|.
            game                  "{GAME_ROOT}/cstrike"
            game                  "{GAME_ROOT}/hl2"
            platform              "{GAME_ROOT}/platform"
        }
    }
}
```

Это предварительный шаблон. Если понадобится изменить `SearchPaths`, меняйте только этот файл и сохраните рабочий вариант.

## 4. Попробуйте оба варианта запуска

Оставьте Steam запущенным. Откройте командную строку в `GAME_ROOT`.

Сначала попробуйте `cstrike.exe`, если он есть:

```bat
cstrike.exe -steam -game "C:\CssTest\profile" -novid -console
```

Если файл отсутствует или запуск не сработал, попробуйте:

```bat
hl2.exe -steam -game "C:\CssTest\profile" -novid -console
```

Запишите, какой вариант сработал, а какой нет, и что произошло: игра открылась, сразу закрылась или показала ошибку.

## 5. Проверьте пути и сборку

После запуска откройте консоль и выполните:

```text
path
version
```

В выводе `path` должны присутствовать профиль, `cstrike`, `hl2`, `platform` и реальные VPK-архивы из установки. В выводе `version` запишите `Build Label` и `Client/Server version`. Также прочитайте `<GAME_ROOT>\cstrike\steam.inf`: для текущей копии ожидается `ClientVersion=11003710`, а Steam `buildid` в `<SteamLibrary>\steamapps\appmanifest_240.acf` равен `25338318`. Это разные идентификаторы.

Дойдя до главного меню, убедитесь, что нет `Can't find background image` и других ошибок загрузки ресурсов. Затем запустите тестовую карту, например `map de_dust2`, и проверьте наличие текстур, моделей и звуков. Это обязательная smoke-проверка перед выпуском.

## 6. Проверьте `custom/`

Выйдите из игры и положите в `C:\CssTest\profile\custom\test` тестовый ресурс с корректным путём, например прицел из `materials`, звук из `sound`, модель из `models` или ресурс HUD. Запустите игру повторно и проверьте, что изменение видно.

Если изменение не применилось, проверьте вывод `path`, строку `custom/*`, порядок `SearchPaths` и структуру каталогов ресурса. Первый найденный файл перекрывает остальные.

## Если запуск не работает

- Игра не стартует или закрывается: проверьте запущенный Steam и попробуйте другой exe.
- Ошибка `gameinfo.txt`: проверьте путь в `-game`, кавычки и точное имя файла.
- Нет карт, звуков или моделей: пришлите текст ошибки; возможно, в `SearchPaths` не хватает пути к папке игры.
- `custom/` не подхватывается: проверьте вывод `path`, строку `|gameinfo_path|custom/*` и структуру папок `materials`, `sound`, `models`, `resource`.

Не удаляйте и не редактируйте файлы в папке Steam. Все файлы этой проверки должны находиться в `C:\CssTest`.

## Что прислать разработчику

1. Какие exe лежат в папке игры.
2. Какой вариант сработал: `cstrike.exe` или `hl2.exe`.
3. Полный вывод `path`.
4. Результат `version`, Build Label и содержимое `cstrike\steam.inf`.
5. Steam `buildid` из `appmanifest_240.acf`.
6. Работает ли загрузка файлов из `custom/`.
7. Рабочий вариант `gameinfo.txt`, если его пришлось менять.
8. Текст ошибок или скриншоты.
