# CS:L — Counter-Strike: Source Launcher

CS:L — лаунчер для официальной Steam-установки Counter-Strike: Source. Он ищет игру в библиотеках Steam, проверяет клиент, открывает установку через Steam, позволяет выбрать папку вручную и запускает выбранный `cstrike.exe` или `hl2.exe`.

## Запуск без профилей

CS:L не создаёт профили, не генерирует копии `gameinfo.txt` и не добавляет параметр `-game`. Игра запускается непосредственно из `<GAME_ROOT>` с официальным `<GAME_ROOT>\cstrike\gameinfo.txt`. Папка Steam, VPK и DLL игры не изменяются.

Эквивалент обычного запуска:

```bat
cstrike.exe -steam -novid -console
```

Если `cstrike.exe` отсутствует, можно выбрать `hl2.exe`. Перед запуском CS:L проверяет наличие официального `cstrike\gameinfo.txt`, а перед повторным запуском снова проверяет состояние клиента.

## Кнопки начального экрана

- **Установить через Steam** открывает официальный `steam://install/240`.
- **Выбрать папку** проверяет выбранный каталог игры.
- **Проверить снова** повторяет поиск в библиотеках Steam после установки.
- **ИГРАТЬ** запускает игру только после успешной проверки.
- Вкладка **Серверы** загружает локальный JSON или HTTPS-список.
- Вкладка **Диагностика** создаёт ZIP с настройками, логами и сведениями о версии без копирования файлов Valve.
- Вкладка **Восстановление** работает только с резервными копиями `settings.json` и позволяет сбросить локальные настройки.

## Smoke-проверка запуска

Перед выпуском новой версии на реальной Windows-установке откройте игру через лаунчер, затем в консоли выполните:

```text
path
version
```

В `path` должны быть видны реальные `cstrike`, `hl2`, `platform` и VPK-архивы. Главное меню должно открыться без `Can't find background image` и ошибок монтирования. После этого загрузите тестовую карту, например `map de_dust2`, и проверьте текстуры, модели и звуки. Полная инструкция находится в [docs/manual-check-game-launch.md](docs/manual-check-game-launch.md).

## HUD 0.4.0

Ветка 0.4.0 содержит архитектуру собственного HUD-плагина с режимом `replace`, приоритетом `zOrder: 1000`, отключением штатного HUD только после проверки совместимости и безопасным fallback в `overlay`. Описание находится в [docs/hud-architecture-0.4.md](docs/hud-architecture-0.4.md).

Сейчас в репозитории нет проверенной DLL и нет подтверждённого безопасного способа загрузки клиентского плагина в конкретный Steam build CS:S. Поэтому `hud/hud.manifest.json` и `hud/cfg/hud.json` являются декларацией и конфигурацией, а не активным runtime. HUD нельзя считать видимым и нельзя включать DLL-инъекцию вслепую. До появления проверенного runtime игра продолжает запускаться без изменений.

Фаза A исследования находится в [docs/hud-phase-a-research.md](docs/hud-phase-a-research.md). Файловый HUD планируется размещать только в `cstrike/custom/csl_hud`; это согласованное узкое исключение из правила «не трогать папку Steam». Оригинальные VPK, DLL и `gameinfo.txt` не изменяются.

CS:L HUD работает только с `-insecure`. При включённом HUD лаунчер принудительно добавляет этот параметр, а будущий runtime обязан самостоятельно отказать в загрузке без него. Режим означает «без VAC, только серверы без VAC»: подключаться с HUD к VAC-серверам нельзя и не должно быть никакого обхода VAC. Не тестируйте неподтверждённый runtime на основном аккаунте.

## Данные и безопасность

Настройки и логи хранятся в `%AppData%\CssLauncher\`. Резервные копии настроек находятся в `%AppData%\CssLauncher\backups\settings`. CS:L не требует администратора, не распространяет файлы Valve и передаёт аргументы через `ProcessStartInfo.ArgumentList`.

Если запуск не работает, откройте вкладку **Диагностика**, сохраните ZIP, приложите вывод `path` и `version`, выбранный exe и Steam `buildid`. Не удаляйте и не редактируйте файлы в папке Steam.

## Сборка

Локальная машина разработчика может не иметь .NET SDK. Поддерживаемая сборка выполняется GitHub Actions на Windows: restore, build, тесты, self-contained `win-x64` publish и Inno Setup installer.

Для локальной Windows-проверки:

```powershell
dotnet build CSL/CssLauncher.sln -c Release -p:EnableWindowsTargeting=true
dotnet test CSL/tests/CssLauncher.Tests/CssLauncher.Tests.csproj -c Release
```

Пока не пройдена реальная smoke-проверка и не проверен runtime HUD, стабильный `0.4.0` публиковать нельзя.
