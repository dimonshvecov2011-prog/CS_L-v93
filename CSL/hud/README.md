# CS:L HUD runtime (0.4.0 development)

Это заготовка собственного внутриигрового HUD-плагина CS:L. Runtime пока не активируется и не копируется в профиль автоматически: сначала нужно подтвердить совместимый способ загрузки клиентского плагина на целевом Steam build Counter-Strike: Source.

Файлы:

- `hud.manifest.json` — ABI, build gate, режим `replace`, z-order и fallback.
- `cfg/hud.json` — безопасные настройки HUD; `enabled` по умолчанию `false`.

Приоритет собственного интерфейса задаётся явно через `mode: replace`, `zOrder: 1000` и `disableValveHud: true`. Если Source не позволяет безопасно скрыть штатную панель, runtime обязан перейти в `overlay` и записать конфликт в диагностику. При несовместимости HUD отключается, а игра продолжает запускаться.

Не копируйте DLL вручную в папку Steam и не включайте runtime до появления проверенной DLL для конкретного build. Оригинальные VPK/DLL игры не изменяются.
