# CS:S v93 и CS:L

Репозиторий объединяет исходники проекта модификации **CS:S v93** на базе Source SDK Multiplayer и **CS:L** — отдельный Windows-лаунчер для установленной через Steam Counter-Strike: Source. Работа над исходниками мода и лаунчером ведётся раздельно.

CS:S v93 пока находится в разработке. Текущая проверка базового клиента/сервера описана в документации: воспроизведение запуска подтверждено не полностью, известна проблема падения клиента после инициализации рендерера. Лаунчер CS:L — WPF-приложение на .NET 8: оно находит Steam-установку, проверяет совместимость, хранит фиксированные профили и помогает запустить игру. **Лаунчер не содержит игровые файлы Valve и не заменяет установку или авторизацию Steam.** В CS:L нет каталога сторонних модификаций; профили не предназначены для пользовательских изменений.

## Структура репозитория

| Путь | Назначение |
|---|---|
| `mp/src/` | Исходники и VPC-проекты Source SDK Multiplayer, используемые для разработки CS:S v93. |
| `mp/game/css93/` | Файлы конфигурации и структура игрового мода CS:S v93. |
| `sp/src/` | Исходники Source SDK Singleplayer, сохранённые в репозитории. |
| `CSL/` | Исходники Windows-лаунчера CS:L, тесты, конфигурация и установщик. |
| `docs/` | Руководства по сборке, известные проблемы и проектные заметки. |
| `tools/` | Вспомогательные инструменты проекта. |
| `LICENSE`, `thirdpartylegalnotices.txt` | Лицензионные условия и notices, требуемые для SDK-исходников. |
