# CS:S V93

Наследник ClientMod v34 на публичном Source SDK 2013 Multiplayer.

## Структура

- `mp/src/` — исходники и VPC-проекты Source SDK Multiplayer.
- `mp/game/css93/` — мод, `gameinfo.txt`, конфигурация и будущий контент.
- `tools/` — вспомогательные скрипты сборки и проверки.
- `docs/` — инструкции, решения и журнал проблем.

Каждая фича должна приходить отдельным небольшим коммитом с описанием проверки.
