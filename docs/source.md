# Источник базы и лицензия

База проекта — [Source-SDK-Resources/source-sdk-vs2022](https://github.com/Source-SDK-Resources/source-sdk-vs2022). Выбранный форк содержит multiplayer-исходники в `mp/src`, игровой каталог в `mp/game` и VPC-генератор в `mp/src/createallprojects.bat`.

На момент фиксации проект строится от upstream-коммита:

```text
f8589ca23a00c1fc767eabcb844cc19597da60ca
```

Сообщение этого коммита: `Improve the .gitignore`, дата: 2023-11-20. Наши изменения добавляются поверх него; при обновлении форка базовый commit нужно менять отдельным коммитом и повторно проверять сборку.

В корне базы сохранены оба обязательных файла Valve:

- `LICENSE` — SOURCE 1 SDK LICENSE;
- `thirdpartylegalnotices.txt` — уведомления о стороннем коде.

Их нельзя удалять или заменять. При распространении SDK либо существенной его части необходимо соблюдать условия `LICENSE`, включая бесплатное распространение и сохранение обязательных юридических оговорок.

Этот проект не использует утёкшие исходники, бинарный патчинг оригинального клиента или закрытые ассеты CS:S.
