# История изменений

Здесь фиксируются заметные изменения CS:L в формате [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии 0.3.2 и 0.3.1 описывают состояние исходников по документации и Git-истории: соответствующие теги/публичные релизы в репозитории не создавались. Это не означает, что для этих версий выпущены установщики как GitHub Releases.

## [Unreleased]

Текущая ветка `main` содержит исходники CS:L 0.3.2. Тег `v0.3.2` и публичный GitHub Release не опубликованы.

### Добавлено

- Выбор между найденными `cstrike.exe` и `hl2.exe` с сохранением выбора; единственный найденный исполняемый файл определяется автоматически.
- Повторная проверка Steam-библиотек после перехода к установке игры, ожидание её обнаружения и возможность указать каталог вручную.
- Явное подтверждение запуска при обнаруженных расхождениях SHA-256.
- Резервное сохранение повреждённого `settings.json` в `.bak` и регрессионные тесты ключевых сценариев лаунчера.

### Исправлено

- Поиск принимает только полную установку CS:S и продолжает проверять следующие библиотеки, если предыдущая пуста или неполна.
- Кнопка запуска блокируется на время работы игры и вновь становится доступной после завершения процесса или ошибки.
- Выбранный профиль синхронизирован между вкладками, сохраняется в настройках и безопасно сбрасывается на `Classic`, если сохранён неизвестный ID.
- Параметры выбранного профиля применяются при запуске. Запись настроек выполняется через временный файл с заменой; обработаны ошибки сохранения при закрытии.
- Сведения о версии сбрасываются перед повторной проверкой, а диагностический архив создаётся в фоновом потоке.

### Уточнено

- `Classic`, `Modern` и `Competitive` — фиксированные профили параметров запуска, а не каталог модификаций.
- Канал автообновления лаунчера оставлен неактивным до завершения требований безопасности и тестирования. Проверка/загрузка архива не должна трактоваться как установленное самообновление.
- Серверный JSON поддерживается локально и по HTTP(S), но приложенный `servers.example.json` — демонстрационный пример с адресами-заглушками, а не список доступных серверов.

## [0.3.1] — описание исходников

Для 0.3.1 отдельный тег или публичный релиз в репозитории не найден; запись основана на `CSL/README.md` и изменениях Git.

### Добавлено и сохранено

- Три встроенных профиля запуска: `Classic`, `Modern` и `Competitive`; отдельные каталоги профилей не изменяют оригинальную установку Steam.
- Поддержка списка серверов из локального JSON или HTTP(S)-источника.
- Сбор диагностического ZIP с настройками, логами, сведениями об установке Steam и выбранным профилем.
- Чтение манифеста обновления и проверка версии; при настроенном защищённом канале загрузка проверяется по размеру и SHA-256.

### Исправлено

- Уточнены поиск и проверка установленной игры, выбор исполняемого файла, обработка профилей и проверка версии.
- Улучшены безопасная загрузка обновления и тестовое покрытие сервисов.

### Удалено или ограничено

- Удалён менеджер сторонних модификаций. CS:L не предоставляет пользователям каталог для добавления собственных изменений; `custom` зарезервирован под контролируемые ресурсы проекта.

## [0.3.0] - 2026-11-24

### Добавлено

- Обновлённая оболочка CS:L для Windows, обнаружение установок Steam и переход к официальной установке CS:S через Steam.
- Профили `Classic`, `Modern` и `Competitive`.
- Первоначальные функции каталога модификаций с проверкой SHA-256 и безопасной распаковкой архива. Этот функционал был удалён в последующей работе над 0.3.x и не входит в текущий план.
- Загрузка списка серверов из JSON и базовая проверка манифеста/загрузка обновления лаунчера.
- Диагностический архив и сборка лаунчера для Windows через GitHub Actions.

## [0.2.0] - 2026-11-24

### Добавлено

- Базовый Windows-лаунчер CS:L с обнаружением Steam-библиотек, выбором каталога игры и созданием внешнего профиля запуска.
- Открытие официального Steam URI для установки CS:S; файлы игры и лицензия остаются под управлением Steam.
- Базовая проверка версии по `steam.inf`, настройки и журналы в профиле пользователя.
- Начальная инфраструктура сборки self-contained приложения и Windows-установщика.
