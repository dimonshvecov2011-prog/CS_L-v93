# История изменений

Здесь фиксируются заметные изменения CS:L в формате [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Записи 0.3.2 и 0.3.1 описывают состояние исходников по документации и Git-истории; соответствующие теги и публичные релизы для них ранее не создавались.

## [Unreleased]

Изменений пока нет.

## [0.3.6] — hotfix SearchPaths

### Исправлено

- Профиль больше не требует фиксированные имена отдельных CS:S/HL2/platform VPK-файлов. SearchPaths указывают на стандартные каталоги, откуда Source загружает архивы и loose-файлы; это устраняет ложные ошибки «Не найден SearchPath» на штатных установках.
- Добавлен regression-тест на реальный production template и структуру установки без этих отдельных VPK-имён. Steam-файлы не изменяются.

## [0.3.5] — стабильность, резервирование и восстановление

### Добавлено

- История последних пяти валидных копий настроек в `%AppData%\CssLauncher\backups\settings`, список в UI, подтверждаемое восстановление и предложение последней рабочей копии после обнаружения повреждённого или чрезмерно большого JSON.
- Staging-перегенерация профилей с проверкой `gameinfo.txt`/SearchPaths, сохранением предыдущей версии, откатом выбранной копии и подтверждаемым factory reset; данные Steam-папки игры не изменяются.
- Маркер незавершённого запуска, recovery prompt, режим `--safe-mode` и per-user single-instance Mutex.
- Изолированная транзакционная функция updater-а для fake-channel тестов: staging, проверка размера/SHA-256, отклонение небезопасных ZIP-путей, сохранение предыдущей версии и автоматический rollback, если health confirmation не пришёл вовремя.
- В диагностический ZIP добавлен инвентарный список резервных копий; их содержимое не вкладывается целиком.
- Валидный профиль повторно используется; при обновлении шаблона сохраняются пользовательские файлы, а factory reset создаёт чистое состояние с резервированием прежней версии.

### Исправлено

- Перед каждым запуском заново проверяются версия/состояние сборки и целостность профиля; изменение состояния требует явного подтверждения.
- Валидация профиля учитывает только SearchPaths внутри FileSystem, откат проверяет копию до замены, а операции с профилями/backup блокируют symbolic links.
- SHA-256 updater-пакета и ZIP-распаковка используют один открытый поток, чтобы исключить подмену пакета между проверкой и установкой; диагностический ZIP пропускает reparse points.
- Исключения из поиска Steam-библиотек передаются в лог; основные WPF async-обработчики отображают и логируют ошибки.
- Factory reset синхронизирует состояние UI, чтобы закрытие окна не восстановило старые настройки.

### Ограничения релиза

- Реальный update feed остаётся пустым и отключённым. Транзакционный engine проверяется только на fake-channel пакетах и не заменяет работающий процесс; интеграция с отдельным bootstrapper-ом и запуском на Windows требуется до включения самообновления.
- Запуск WPF и визуальная проверка recovery UI доступны только на Windows; в текущей среде подтверждаются cross-target build и xUnit tests.

## [0.3.3] — 2026-11-25

### Добавлено

- Полностью обновлён интерфейс WPF: новая тёмная тема, отдельные вкладки, прокручиваемые панели, переносимые параметры запуска и компактная компоновка для небольшого рабочего стола.
- Добавлены кастомный заголовок окна с перемещением, свертыванием, максимизацией и закрытием; включён нативный WPF `WindowChrome` для изменения размеров по краям.
- Добавлены регрессионные тесты для ограничений updater-а и отмены запроса, неизвестной схемы настроек, executable и symlink-пути, списка серверов, размера отдельной записи логгера и форматирования SHA-предупреждения.

### Исправлено

- Стартовые размеры окна и боковая панель адаптируются к рабочей области; на узком экране боковая панель скрывается, панели прокручиваются вместо обрезания содержимого.
- Updater читает локальный JSON без зависимости от регистра, отклоняет HTTP, контролирует HTTPS после redirect, ограничивает размер манифеста и загрузки, требует точный размер и проверяет SHA-256 до сохранения архива; отмена, запрошенная вызывающим кодом, не поглощается.
- Список серверов принимает удалённый источник только по HTTPS, проверяет схему и поля, ограничивает размер ответа и количество записей.
- Неизвестный `schemaVersion` настроек вызывает явное предупреждение и не приводит к перезаписи исходного JSON; сохранение остаётся атомарным.
- Запуск принимает только `cstrike.exe` или `hl2.exe` из корня найденной игры и отклоняет символьные ссылки на executable вне этой папки; Steam-процессы освобождаются корректно, а исключения в логах включают детали.
- `knownBuilds` используется только для диагностической подсказки и не подменяет проверку `ClientVersion`.
- `publish.ps1` проверяет ненулевой код `dotnet publish` и наличие итогового `CSL.exe`; GitHub Actions сверяет версию тега с версиями приложения и Inno Setup перед созданием релиза.

### Удалено

- Удалены единственные подтверждённые неиспользуемые элементы: дублирующий сервис `ProfileService.cs`, его контракт `IProfileService` и тест, который использовал только legacy-реализацию. Unicode-путь теперь проверяет используемый приложением `ProfileCatalogService`.

### Ограничения релиза

- Auto-update канал оставлен неактивным до публикации доверенного HTTPS-пакета и его SHA-256. Текущая функция проверки скачивает и проверяет архив, но не устанавливает его и не изменяет файлы игры.
- Игровые файлы Valve не включаются в репозиторий, установщик или диагностический архив; менеджер пользовательских модификаций не добавлен.
- Интерактивное отображение WPF и проверка DPI должны быть подтверждены на Windows; локально проверяется сборка и тесты.

## [0.3.2] — описание исходников

Для 0.3.2 отдельный тег или публичный релиз в репозитории не найден; запись основана на README и Git-истории до релизного кандидата 0.3.3.

### Добавлено

- Выбор между найденными `cstrike.exe` и `hl2.exe` с сохранением выбора; единственный найденный исполняемый файл определяется автоматически.
- Повторная проверка Steam-библиотек после перехода к установке игры, ожидание её обнаружения и возможность указать каталог вручную.
- Явное подтверждение запуска при обнаруженных расхождениях SHA-256.
- Резервное сохранение повреждённого `settings.json` в `.bak` и регрессионные тесты ключевых сценариев лаунчера.

### Исправлено

- Поиск принимает только полную установку CS:S и продолжает проверять следующие библиотеки, если предыдущая пуста или неполна.
- Кнопка запуска блокируется на время работы игры и вновь становится доступной после завершения процесса или ошибки.
- Выбранный профиль синхронизирован между вкладками, сохраняется в настройках и безопасно сбрасывается на `Classic`, если сохранён неизвестный ID.
- Параметры выбранного профиля применяются при запуске. Запись настроек выполняется через временный файл с заменой; обработаны ошибки сохранения при закрытии.
- Сведения о версии сбрасываются перед повторной проверкой, а диагностический архив создаётся в фоновом потоке.

### Уточнено

- `Classic`, `Modern` и `Competitive` — фиксированные профили параметров запуска, а не каталог модификаций.
- Канал автообновления лаунчера оставлен неактивным до завершения требований безопасности и тестирования.
- Серверный JSON поддерживает локальный файл и HTTP(S)-источник; приложенный `servers.example.json` — демонстрационный пример с адресами-заглушками.

## [0.3.1] — описание исходников

Для 0.3.1 отдельный тег или публичный релиз в репозитории не найден; запись основана на `CSL/README.md` и изменениях Git.

### Добавлено и сохранено

- Три встроенных профиля запуска: `Classic`, `Modern` и `Competitive`; отдельные каталоги профилей не изменяют оригинальную установку Steam.
- Поддержка списка серверов из локального JSON или HTTP(S)-источника.
- Сбор диагностического ZIP с настройками, логами, сведениями об установке Steam и выбранным профилем.
- Чтение манифеста обновления и проверка версии; существующий прототип загрузки требовал дальнейшего hardening.

### Исправлено

- Уточнены поиск и проверка установленной игры, выбор исполняемого файла, обработка профилей и проверка версии.
- Улучшены безопасная загрузка обновления и тестовое покрытие сервисов.

### Удалено или ограничено

- Удалён менеджер сторонних модификаций. CS:L не предоставляет пользователям каталог для добавления собственных изменений; `custom` зарезервирован под контролируемые ресурсы проекта.

## [0.3.0] — 2026-11-24

### Добавлено

- Обновлённая оболочка CS:L для Windows, обнаружение установок Steam и переход к официальной установке CS:S через Steam.
- Профили `Classic`, `Modern` и `Competitive`.
- Первоначальные функции каталога модификаций с проверкой SHA-256 и безопасной распаковкой архива. Этот функционал был удалён в последующей работе над 0.3.x и не входит в текущий план.
- Загрузка списка серверов из JSON и базовая проверка манифеста/загрузка обновления лаунчера.
- Диагностический архив и сборка лаунчера для Windows через GitHub Actions.

## [0.2.0] — 2026-11-24

### Добавлено

- Базовый Windows-лаунчер CS:L с обнаружением Steam-библиотек, выбором каталога игры и созданием внешнего профиля запуска.
- Открытие официального Steam URI для установки CS:S; файлы игры и лицензия остаются под управлением Steam.
- Базовая проверка версии по `steam.inf`, настройки и журналы в профиле пользователя.
- Начальная инфраструктура сборки self-contained приложения и Windows-установщика.
